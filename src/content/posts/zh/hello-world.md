之前这个站点只有一页：个人简介、论文、技能、项目、教育全堆在一起，靠锚点跳转。内容越来越多之后，一页里塞不下「想长期写的东西」——比如读论文的记录、做项目时踩的坑。

所以改成了现在这个结构：

- `/` 是关于我，也就是原来那一页，简历信息都在里面
- `/blog/` 是文章列表，以后写的东西都放这儿
- `/archive/`、`/categories/`、`/tags/` 是三种不同的翻找方式
- 顶栏右侧的放大镜可以搜索全文

## 为什么选 Astro

写博客的框架很多，选 Astro 主要是因为它**默认不输出 JS**。文章内容本来就是静态的，没必要为了渲染一段 Markdown 把整套运行时塞给浏览器。

需要交互的地方（主题切换、搜索、窄屏菜单）再单独加一点点脚本，其余都是纯 HTML + CSS。

## 内容怎么组织

文章是 `src/content/posts/` 下的 Markdown 文件，中英文各一个目录：

```
src/content/posts/
├── zh/
│   └── hello-world.md
└── en/
    └── hello-world.md
```

文件名就是 URL：`zh/hello-world.md` 对应 `/blog/hello-world/`。加一篇文章只要新建一个 `.md`，写上 frontmatter：

```yaml
---
title: 标题
description: 一句话摘要，会显示在列表页和搜索结果里
date: 2026-08-28
category: 分类
tags: [标签1, 标签2]
---
```

> 文件名建议用英文。URL 里的中文会被转成乱码一样的转义串，不好看也不好记。
