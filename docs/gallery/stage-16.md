# S16 — P0 引擎：弧墙 / 任意方向裁剪 / 线段碰撞 / 多边形天花 / 弧墙挂画

设计方案（`design-interior.md`）里那些形态（弧墙、凹龛、八边形、斜切展墙、跌级天花）
现在的引擎一样都做不了：房间只有矩形、裁剪只认轴对齐、碰撞是 AABB、天花是矩形 plane、
挂画按单段墙排。这一轮把地基换掉 —— **形态一个没动**（那是 P1/P2 的事），
只让引擎具备这些能力，并把原有几何逐点核对到「一个不差」。

## 做了什么

### 1. `walls.ts`：弧墙生成器 `arcWall()`

弧在引擎里没有真曲线：把圆弧按每 0.6 m 拆成一串短墙段，走的还是原来那条
`polylineWalls`（InstancedMesh 的一片片 plane），只是拼成一条弧。
所有段共用同一个 `group` —— 挂画时靠它并回一面墙（见第 4 条）。

```ts
arcWall({ cx, cz, r, from, to, height, zone, group, segments?, side?, kind?, tint?, hero? })
```
`side = +1` 时 normal 指向圆心那侧（与 `polylineWalls` 同一套约定）：房间向外鼓的
弧用 +1，凹进去的龛用 -1。

### 2. `walls.ts`：裁剪换成线段与矩形求交（Liang–Barsky）

`trimWall` 以前按轴切（"横向墙比 x、纵向墙比 z"），遇到斜墙只能整段留 / 整段扔。
现在算出「落在开口里」的那段参数区间 `[t0, t1]`，留下两头 —— 方向无所谓。
开口仍按 `HALF_T` 外扩（墙压在开口边线上时也算进去，与旧行为一致）。

**顺带修掉一个真 bug**：`sliceWall`（去重时按区间切墙）原来从「最小值往最大值」走，
遇到端点反着的墙（顺着折线切出来的段）会把切出来那截**挪错位置** ——
改前在 z=14 那条线上多出 0.30 m 的共面重叠（长廊墙 × 沉浸厅墙，会 z-fighting），
改成沿 a→b 参数插值后归零。

### 3. `plan.ts`：碰撞改成点到线段距离

`containsPoint` 原来是「进没进墙的 AABB」。AABB 对轴对齐的墙是准的，对斜墙 / 弧墙
会胖出一圈（实测弧墙外侧最远多挡 **0.91 m**）。现在：先用 AABB **粗筛**（进都没进
盒子就不可能贴墙），再对候选点算点到线段距离 ≤ `CLEARANCE`（半墙厚 0.1 + 人身 0.35）。

### 4. `hang.ts`：同 `group` 的段并成一面墙，作品沿折线排

- `deriveArtWalls` 先跑一遍 `surfaces()`：同 group 且首尾相接（< 1 mm）的段并成一面，
  不写 group 的墙行为与以前完全一样。并起来的 `ArtWall` 多一个 `path`（折线）。
- `hang()` 落位时：有 `path` 就沿折线走（`alongPath`），每件的**朝向跟着它脚下那段
  墙转**；没有 path（直墙）仍走原来那条 `start→end` 直线插值。
- 弧墙的 hero 标记：任一段带 hero 就算整面是 hero。

不并起来会怎样：R=5.5 的弧拆成 0.6 m 一段，每段都短于最短挂画长度 2.6 m，
**整面弧墙一张都挂不上**。

### 5. `floor.ts`：房间天花走多边形

房间天花从「1×1 plane 拉到房间尺寸」换成 `ShapeGeometry`（矩形就是四点多边形）。
`ShapeGeometry` 的 uv 是形状坐标（米），直接用会把贴图拉爆，所以按包围盒归一到
0–1 —— 与原来那张 plane 的观感一致（见自测）。P1 的八边形大厅、弧形房间直接给
多边形就行，不用再动这段。

## 自测结果

`npm run check`：**0 errors / 0 warnings / 2 hints**。`npm run build`：通过。

### 弧墙能力探针

- 几何：R=5.5 半圆 → 29 段，端点离圆心偏差 **0.0000 m**，弧长 17.270（理论 17.279）
- 挂画：29 段并成 **1 面墙**（17.27 m，折线 30 点）；强制成 standard 后 5 件，
  离弧面 0.052–0.081 m（就是那 6 cm 的离墙缝），**朝向 5 种**（跟着墙转）
- 碰撞：同样一条弧，AABB 会在弧外侧多挡出最远 **0.91 m** 的一圈；点线距没有
- 场景验证：临时在潮汐厅插了一段 R=3 的弧跑了一遍（截图有一道连续的弧面、
  控制台 0 错误），验完已还原

## 接下来做什么

引擎这一层铺好了，P1 可以动形态了：

1. **P1 试点两间**：序厅（南墙微弧 + 北墙主视觉凹龛 + 藻井）、潮汐之间（东墙 R=5.5 +
   三折发光顶）。凹龛需要一个新的 `niche` 数据（沿墙法线退 0.35 的三段墙），
   这一轮没做 —— 做完 P0 它只剩十来行。
2. **P2 全馆**：中央大厅八边形、临展厅 12° 斜展墙（顺带要「斜墙去重」，
   现在 `dropDuplicates` 见到斜墙是直接放行的）、大型厅锯齿墙、总览区漏斗出口。
3. **跌级天花**：一个分区多块天花 + 级间竖向收口面（P0 只做了多边形这一层）。
4. **弧墙与直墙的接缝**：现在斜墙不参与去重，弧的两端接直墙时可能共面闪色，
   P2 做形态时会一起处理。
