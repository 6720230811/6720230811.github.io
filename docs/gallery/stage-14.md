# S14 — 三道口味题落地：序厅压暗、城市右墙拉亮、潮汐顶发光

S13 收尾时规格里没有硬要求了，剩下三条「每条都动 1–2 个分区的脾气」的选择题。
这一轮把三条都定了：

1. 序厅走方案 (a) —— 压暗环境光，进门先暗、往里走才放开；
2. 城市长廊选「拉亮右墙」，不选「压深左墙」；
3. 潮汐之间真的给一面发光的顶（大面积漫射柔光），不只是靠灯槽兜。

## 做了什么

### 1. `Zone.ambient`：分区可以带一个环境光乘数

环境是全场一份（半球光 + `scene.environment`），所以这不是「给某间房点灯」，
是**跟着人走的整体曝光**：站进序厅，整屏压下去；走进城市长廊，再放开。

- `blueprint.ts` / `plan.ts`：`Zone.ambient?: number`（1 = 全馆默认），序厅 `0.3`。
- `floor.ts:applyAmbient`：`hemi.intensity = LIGHTING.ambient * level` +
  `scene.environmentIntensity = level`。
- 出生点第一帧就按 `zoneAt(spawn)` 压好（`zoneAt` 从 `walls.ts` 引），
  不等走出 1.5 m 才变；走动时每帧朝目标插值 6%（≈ 半秒），跨门洞不会整屏跳一下。
- 不写 `ambient` 的分区行为完全不变（`?? 1`）。

```ts
// blueprint.ts：入口序厅
// 环境光压到 0.3：进门先暗，往里走（城市长廊 / 中央大厅）才放开 ——
//  实测整屏平均亮度 序厅 80 / 夜行长廊 93 / 城市长廊 137
ambient: 0.3,
```

### 2. 城市长廊：拉亮右墙，不压深左墙

右墙暖矿物灰泥 `#D7D0C4 → #DFD8CB`。两条路的账算下来不一样：

| | 左墙 | 右墙 | 两面墙的明度差 |
|---|---|---|---|
| 原来 | `#AEA69B`（167） | `#D7D0C4`（209） | 25% |
| 拉亮右墙（选了这个） | `#AEA69B`（167） | `#DFD8CB`（217） | 30% |
| 压深左墙（没选） | `#9A9388`（148） | `#D7D0C4`（209） | 41% |

压深左墙的差更大，但它把「往里走」的那条长廊整体压暗了 —— 跟第 1 条
「先暗再亮，往里走才放开」正好打架。拉亮右墙差得少一点，方向却是一致的：
出门越走越亮。

### 3. 潮汐之间：一面自己会亮的顶

- `Zone.glow?: { color, intensity, fill }` —— 潮汐厅 `#CFE4DC` / `0.55` / `fill 4.5`。
- `floor.ts` 的分区天花材质多带一组 `emissive` + `emissiveMap`：
  **复用同一张 `ceilingTexture`**，S11 烘进去的那道波纹照样调制发光，
  所以顶不是一块死板的白板，是"水面"。
- 再补一盏 `PointLight(4.5, 20, 1.6)` 挂在顶下 0.7 m（照中央大厅那套做的）：
  emissive 面片自己不照亮任何东西，不给它一点真光，厅里就只剩环境光，
  顶看着像贴上去的。

### 亮度探针（整屏平均亮度，0–255）

| 视点 | 分区 | 平均 | p25 / p75 |
|---|---|---|---|
| 出生点朝里 | 入口序厅（`ambient 0.3`） | **80.3** | 30 / 103 |
| 折廊 x=12 | 夜行长廊（默认 1） | 92.6 | 45 / 135 |
| 折廊 x=8, z=10 | 城市长廊 | 136.5 | 106 / 191 |
| 潮汐厅中央 | 潮汐之间 | 87.9 | 65 / 87 |
| 潮汐厅抬头 | 潮汐之间（发光顶） | 92.2 | 80 / 93 |

- 「进门先暗、往里走才放开」成立了：序厅 80 → 长廊 93 → 城市长廊 137，
  序厅比夜行长廊还暗一档（不是简单看齐 —— 它有自己四面墙的色，压到 0.3
  才读得出"另一间厅"）。
- 潮汐厅抬头那张：顶棚近处那条带子平均 121、最亮 255、标准差 53 ——
  亮，但波纹还在（不是一块均匀的白）。
- 主视觉没被压没：序厅那件作品在 80 的底子上还是画面里最亮的一块（248）。

## 接下来做什么

三条都落地了，剩下的还是口味题，等你点：

1. **序厅要不要再给一束光**。现在序厅是纯压暗（方案 a）。方案 (b) 那道
   3500 K 暖色下射光（洗一面前主视觉的深酒红墙）还没做 —— 是现在补上，
   把"进门被打了一束光"做实，还是就停在"先暗"这一档？
2. **潮汐顶要不要再亮一档**。近处那条带子已经到 255 了，但顶棚中段（远处）
   还是 100 出头 —— 是把 `intensity` 从 0.55 提到 0.9（整片顶更"满"），
   还是加 `toneMapped: false`（像中央大厅那块天窗那样，亮得更硬）？
3. **环境光插值要不要跟帧率脱钩**。现在是每帧 6%，60 fps 下约半秒；
   掉到十几帧（软件渲染 / 弱机）时会拖到两三秒。改成按 `dt` 算的一步
   指数平滑（约 5 行），还是就让它跟着帧率走？
4. **还有房间想单独调曝光吗**。`ambient` 现在是通用开关，只序厅用了。
   沉浸展厅（规格要"暗"）、总览区（规格要"亮"）要不要各给一档？

每条都在 1–10 行以内，方向你定。
