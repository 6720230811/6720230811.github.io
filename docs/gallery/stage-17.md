# S17 — P1 试点：序厅的微弧墙 / 凹龛 / 藻井

P0 把引擎的四个能力铺好了（弧墙、任意方向裁剪、线段碰撞、多边形天花、弧墙挂画），
这一轮拿**入口序厅**开刀 —— 它是进门第一眼，也是唯一一间四面墙各有性格的房间。
三件事：南墙微弧、北墙凹龛（主视觉嵌进去）、天花藻井（压暗的厅里唯一的光）。

## 做了什么

### 1. 南墙（入口那面）改成朝外微鼓的弧

- `RoomSpec.arc?: Partial<Record<WallKey, number>>` —— 给某一面墙一个矢高，
  弦就是这面墙的全长。序厅 `arc: { s: 0.35 }`（弦 8 m，R≈23），
  进门时墙往两侧退开一点，"让"出进门的那一瞬。
- `walls.ts:arcPointAt()` 是这次新增的核心：沿墙坐标 s → 弧上那一点，
  用「离弦距离 = -(r-f) + √(r² - x²)」算，两端归零、中点正好是矢高。
  门洞与门廊的收头都靠它 —— 它们得跟着弧走。
- 弧墙拆成每 0.6 m 一段，共用 `group: 'entry-s'`，于是挂画时并回一面 4.52 m 的墙
  （P0 的合并机制）。

**两个必须跟着改的地方**（不然会出现 0.3 m 的错位）：
- **门洞**：序厅南门从 `(4, 0)` 挪到弧上的 `(4, -0.263)`；`ry` 仍是 0 ——
  微弧在门洞那 3 m 上的倾角只有 3.7°，`doorOpenings` 里的 `horizontal` 判定
  （`|ry| < 1e-6`）不能破坏，所以门套仍按直墙摆。
- **门廊侧墙**：序厅门廊那两面侧墙原来收到 z=0，现在按各自 x 处的弧线收头
  （x=2.5 → z=-0.083，x=5.5 → z=-0.345）—— 不然它们会从弧面里戳出来一截。

### 2. 北墙（深酒红）开一个凹龛，主视觉嵌进去

- `RoomSpec.niches?: NicheSpec[]`：{ wall, at, width, depth, top }。
  序厅：北墙 `at: 7.3`、宽 3.4、退 0.4、洞口高 2.8（上面 0.6 m 是龛楣）。
- `walls.ts:roomWalls` 在这面墙上按龛宽挖一段，补两片门垛 + 一片后壁
  （后壁带 `hero` 与 `niche` 两个标记）。
- `hang.ts`：凹龛后壁的墙角预留从 1.2 m 降到 `NICHE_KEEP` 0.15 ——
  不然 3.4 m 的龛扣掉 2.4 m 预留，3 m 的主视觉会被压成 1 m。
- 主视觉的落点：`heroWall: 'n'` + 龛 → 挂**在龛里**（`(7.3, 7.34)`），
  不再是挂在墙面上。
- `floor.ts`：龛楣（洞口顶到天花那截补成墙）+ 龛内两侧各一条 60 mm 竖向暗缝灯
  （3000 K，只洗龛的内壁，不照画）。

**顺手处理的一处冲突**：展览标题原来在北墙正中（x=6，宽 4.6），正好压在
龛口（x 5.6–9）上。标题与它的背光一起让到西边那截（中心 x=4.1，宽 3.2）。

### 3. 天花：中央 4.4 × 5.0 沉 0.35 m 的藻井

- `RoomSpec.coffer?: { x1, z1, x2, z2, drop, slot }`。
- 房间的天花先按井口挖掉一块（P0 的多边形天花 + `subtract`），再补：
  四面井壁（3.4 → 3.05）+ 井底 + 井底四周 180 mm 的灯槽（2800 K，
  比井底低 1 cm 免得共面闪）。
- `slotMaterial(zone, kelvin?)` 加了可选的色温覆盖：藻井 2800 K、
  龛内暗缝灯 3000 K，共用一个分区的槽材质机制。
