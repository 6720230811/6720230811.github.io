# S15 — 地图上标出每一间厅

折廊里最容易丢的不是「我在哪」（小地图上有视锥那一点），而是「大厅在
哪个方向」—— 光看墙的线读不出「这一大块是间厅」。这一轮把七间厅都标
到图上：铺一层极淡的底 + 中心一个空心小圈，大地图上再挂名字。

## 做了什么

### 1. `FloorPlan.spaces`：每间厅的位置与名字

`plan.ts` 从 `ROOMS`（矩形）取位置、从 `zone(id).label`（`{ zh, en }`）取名字，
算一次就够（建筑是静态的，跟着 `skeleton()` 一起缓存）。

**名字不从页面的 `rooms` 拿**：主题视图页（`/gallery/theme-city/`）交进来的
房间是 `theme-city` / `theme-sea`，不是厅。所以厅名走 `ZONES` —— 跟 3D 里
HUD 上那个分区名是同一套，两种语言都在。

```ts
spaces: ROOMS.map((room) => ({
  id: room.id,
  rect: room.rect,
  label: zone(room.id).label,
})),
```

### 2. `minimap.ts:paintBase`：铺底 → 墙 → 圈 + 名字

- 先给每间厅铺一层 `rgba(246, 190, 118, 0.07)`，极淡，只是让「厅」跟
  「折廊」在图上分成两种底色；
- 墙照旧合成一条路径描一次（不铺底的话七个圈会浮在线上，看不出是房间）；
- 每间厅中心一个空心小圈（暖强调色，跟人那一点同一个色系但空心的）；
- **名字只在 ≥ 260 px 的那张图上写**（`LABEL_MIN`）：小地图 152 px 写七个
  名字会糊成一团，所以小地图只留圈。用 S5 就备好的 `label()`（白字 +
  暗描边，密线上也读得清）—— 这个函数之前一直没被用到。

### 3. `index.ts`：两张图都要知道页面语言

厅名是 `{ zh, en }` 两份，`createMinimap` / `createBigMap` 现在都收
`{ hall, locale }`（`locale` 来自 `localeOf()`）。

## 自测结果

`npm run check`：**0 errors / 0 warnings / 2 hints**（原先 3 个 ——
`minimap.ts` 里那个「`label` 声明了没用」的 hint 这轮正好用上了）。
`npm run build`：通过。

## 接下来做什么

1. **长廊的章节要不要也标**。现在标的是七间厅，折廊那六章（夜行 / 城市 /
   自然 / 光影 / 慢门 / 终章）只有墙没有名字 —— 是沿折线在拐弯处标个
   章节号，还是只在尽端墙上标？
2. **当前所在的那间厅要不要高亮**。人那一点已经很清楚了，但「我正站在
   哪间厅里」得自己把圈和点对上 —— 给当前厅的圈换个实心/加粗（约 6 行）。
3. **小地图要不要给 1–2 字的短名**。152 px 上写全名会糊，但写「序」「潮汐」
   这种两字缩写也许还行 —— 或者干脆保持只有圈。
4. **大地图在矮窗口里被压扁了**。视口 800 px 高时画布被 flex 压到 307 px
   （`.gal__map-canvas` 没设 `flex: none`），名字跟着缩到 10 px。要不要
   给个下限？
