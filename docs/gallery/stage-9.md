# S9 — 入口序厅四面墙（各色 + 墙上的字）

规格第四节给了序厅四面墙各自的性格，S2 只给了「四面同色的一个房间」。这一轮补上。

## 做了什么

### 1. 四面墙四面色

`RoomSpec` 新增 `wallColors`（目前只有序厅用），`WallSegment` 多了一个 `tint` ——
墙色不再只能按分区给，同一间房里四面可以各一个色：

| 墙 | 颜色 | 内容 |
|---|---|---|
| 南（入口） | `#232726` | 入口开口，门洞周围深石墨 |
| 北（主视觉） | `#4A202A` | 深酒红 + 展览标题 |
| 西 | `#C7BFB3` | 展览介绍 / 策展文字（深字 `#343432`） |
| 东 | `#3D4443` | 嵌墙式发光平面图 + 操作说明 |

肌理仍走 `mineralTexture`，只是按「分区 + 色」缓存，同一色只画一张。

### 2. 墙上的字与那张平面图

新增两个贴图函数（都在 `surfaces.ts`）：

- `wallTextTexture()`：透明底，直接把字画在墙面上（规格：文字区背后不设复杂纹理）。
  字多自动折行并缩字号，放不下就截断。
- `planPanelTexture()`：东墙那张「嵌墙式发光图」——用 `plan.walls` 把整馆平面
  以低亮度青铜线（`#896A47`）画在深色底上，房间块用极淡的青铜填满。
  不是电子屏幕，是刻在墙里的一张图；底下再压一行操作说明。

具体挂了四样：

- **北墙**：展览标题（暖象牙白 `#E6E0D6`），背后一层很淡的暖光 ——
  规格说「不要强光立体字，只做柔和背光」，所以字是平的、只有一圈微光。
- **西墙**：策展文字，取当前展厅的 `intro`（数据里的，不是写死的）。
- **东墙**：平面图 + 操作说明（东墙被 4 m 的门洞切掉大半，图挂在剩下那截上）。
- **短隔墙**：朝入口那一面写一句话；隔墙本身改成规格的 3.1 m 高、色 `#D7D0C4`
  （背面留给第一件作品）。

文案走 i18n（`gallery.wall.title / curator / hint`），由页面 `data-label-*` 传进场景 ——
场景不认得语言，只认传进来的一串字。

### 3. 门洞的青铜压边（规格十三节）

每道门洞内侧加一道 8 mm 做旧青铜压边（`#896A47`，roughness 0.48 / metalness 0.38，
不发金色强反光）。做成扁盒子、上下各短 2 cm —— 不短就会与门套顶面、地面共面（又会闪）。

## 自测结果

`npm run check`：**0 errors / 0 warnings / 3 hints**。`npm run build`：通过。

几何探针（临时挂 window，用完已删）：

- 墙色分组里能取到序厅那四支：`#4E262F`（北，酒红带肌理后取样值）、`#C7BFB3`（西）、
  `#424948`（东）、`#272B2A`（南）各 1–2 段 ✓
- 青铜门压边：**26 个实例 = 13 道门 × 2** ✓
- 墙上的四块 + 背光：标题 4.6×1.15 @ (6, 2.05, 6.98)、背光 5.2×1.7、策展文字 4.2×2.1 @ 西墙、
  平面图 2.6×1.3 @ 东墙、操作说明 2.4×0.5、短隔墙一句 2.5×0.9 ✓ 朝向都对（yaw π / π/2 / −π/2）
- 共面异材质对 **41**，与上一轮持平（青铜压边上下都短了 2 cm，没引入新的共面）
- 20 机位画面对比：只有序厅那 5 个机位明显变暗（平均亮度 174 → 124，
  极暗像素 2k → 142k）—— 序厅三面墙本来就是深色（深石墨 / 深酒红 / 青灰），
  这是规格要的「入口处戏剧性」，不是失误；其余机位变化 ≤ 3/255；0 console errors

## 接下来做什么

- 剩下的墙面细节：**城市长廊左墙**要「暖混凝土灰 `#AEA69B` + 微水泥质感」，
  现在左墙跟别区一样是矿物灰泥 —— 需要按墙的左右分别给材质（跟这次的 `tint`
  是同一套机制，可以再扩一个「按朝向」的规则）。
- 几处「光」的细节：潮汐之间顶面的极轻微波纹明暗、临展厅的规则轨道灯（`#363938`）、
  沉浸展厅入口与地面边缘的低亮度引导光。
- 序厅变暗之后，如果觉得第一眼太重：要么把西墙那块浅米再放大一点，
  要么把序厅的作品灯调亮 —— 说一声我调。
