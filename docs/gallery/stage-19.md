# S19 — 长廊也能开壁龛：夜行三处 + 城市端景前的停顿区

到 S18 为止，「拆方盒子」只发生在房间里 —— 长廊还是两段墙夹一条走道。
这一轮把壁龛这件事从房间推广到长廊（长廊占总可参观面积 65–70%，
不在那儿动手，走进去还是两片平板）。

## 做了什么

### 1. `CORRIDOR_NICHES`：长廊墙上的壁龛

房间那套 `niches` 挂在 `RoomSpec` 上（「哪面墙 + 沿墙坐标」），长廊没有四面墙 ——
它的墙是折线偏移出来的。所以新写了一条路：

- `walls.ts:nicheInSegment(wall, from, to, spec)` —— **通用**的：给任意一段墙 +
  沿墙的两个位置，切两截 + 两片门垛 + 一片后壁。房间那套与它共用 `NicheOpening`
  （场景里的龛楣、龛台、暗缝灯于是自动就有了）。
- 定位用**世界坐标投影**（`locatePoint`：取离这个点最近的那段墙），
  **不用弧长** —— 转角处「最近的中心线点」有两解（前后两段等距），弧长会跳，
  试过按弧长定位，三处龛里有两个落到了不该落的段上。
- **先挖龛再裁墙**：开在穿堂房间范围内的龛会被裁墙那一步一起裁掉 ——
  第一版把一龛开在序厅里（x 2–10 / z 0–7 的长廊墙是序厅的墙），直接消失了。
- 左右：`side = +1` 那一侧在行进方向的**右手边**（与长廊竖缝那套 `side` 判定一致）。

### 2. 夜行长廊三处壁龛

0.9 宽 × 0.75 高、退 0.35、龛底 1.35（视线高）、内衬暗石墨（与那道竖缝同色）。
位置 x 11.4 / 13.1 / 14.8（z=3 那道墙上）—— 间距不规则，是「被水冲出来的孔」，
不是装饰节奏。三处都在序厅之外（序厅把 x 2–10 / z 0–7 的长廊墙裁掉了）。

### 3. 龛台：壁龛可以不落地

`NicheSpec` / `NicheOpening` 加 `bottom`：离地的壁龛下面那截补成墙（龛台），
暗缝灯的上下界也跟着改（原来是从地面到龛顶）。

### 4. `CORRIDOR_PATCHES`：城市长廊端景墙前的停顿区

2.4 × 2.4 的深色地面（`#4E4A44`）—— 站上去就知道该停了。
`FloorPatch` 加了可选 `zone`（长廊里的换色块没有房间可以挂，得自己说铺装模块）。
