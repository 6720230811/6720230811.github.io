# S20 — 领口长廊三章：光影有百叶，慢门有拖影，终章有弧

S19 把壁龛带进了长廊，这一轮处理「接下来做什么」的第 1 条：长廊后半段
（光影 / 慢门 / 终章）各补一处特征段。到这轮为止，长廊六个章节里
只剩夜行和城市沿用 S17–S19 的手法，其余四章都有了自己的动作。

## 做了什么

### 1. 光影长廊：天花竖向百叶（`CORRIDOR_LOUVERS`）

x 20–28 共 8 m、80 × 25 @140 mm 的铝合金叶片挂在天花下（底 3.76，净高 4），
叶片后面贴天花藏一条 3500 K 的洗顶光带：正视时藏在叶缝后，走起来从缝里漏出来。
叶缝还在右墙（行进方向右手，与竖缝那套 side 判定一致）画了同间距的竖条纹
（画上去的，不开 shadowMap——全馆就这一处，不值当）。

### 2. 慢门长廊：墙脚连续光槽（`CORRIDOR_WALL_LIGHTS`）

从光影转角那个凹角起，沿右墙往西 9 m 再拐向南 3 m，共 12 m 不中断：
60 mm 宽、贴地 300 mm 起、4000 → 3400 K 沿途渐变。渐变按 2 m 一段切材质
（emissive 不吃 instanceColor），十几段共用一份材质缓存。
地面模块同时换成 0.6 × 4.8 的纵向长条——与拖影同向。

### 3. 终章：尽头转角做成 1/4 圆弧（`CORRIDOR_ROUNDS`）

`walls.ts` 新增通用的凸角倒圆（`cornerArc`）：给折点 + 半径，切点内移、
圆弧替换尖角，生成的短段带 group 并成一面墙。半径受相邻段长度限制，
越界退回尖角。(34, 8) 取 R = 3——从城市端景走到出口，墙不是撞上来再转，
而是一路磨圆着把人送过去。凹角仍走 0.05 m 倒角。

### 4. 弧墙不挂画（`hang.ts:flatSpan`）

转角倒圆生成的「墙」有 4.7 m 长，比最短挂画线还长——但那是转角。
`flatSpan` 按弦高反推一片平画贴上去两端会陷进墙里的宽度（弦高按平方走，
容差 5 cm），不够挂最窄的画（1.1 m）就不挂。这轮全馆只干掉这一面，
序厅微弧那种弦高 < 1 cm 的不受影响。

### 5. 特征段不挂画（`hang.ts:featureCoverage`）

修截图时发现的真问题：慢门那条光槽被画挡成两截——挂在 z=18 墙上的占位画
（光晕板是画幅的 2.3 倍，贴墙一大片）整段压在光槽前面。规则：墙面每 0.5 m
取一个样本点到特征折线（光槽路径 + 百叶条纹带）算距离，超过一半落在
0.25 m 内的墙不挂画。这轮让掉了两面：慢门的 z=18（光槽整段）和光影的
z=21（条纹带）。光槽墙是主角，画挂别的墙。

### 6. 光槽朝向修正（`floor.ts`）

探针抓到的第二个问题：光槽每段的朝向原来取「段中点指向中心线最近点」的
向量——在转角附近最近点有歧义（两段等距），x=23 那两段被转歪了 14°，
一端栽进墙里，看起来就是光槽断成两截。改成法向取垂直于段方向、正负号才
看中心线，槽恢复贴墙连续。

## 自测结果

`npm run check`：**0 errors / 0 warnings / 2 hints**（与上轮相同）。
`npm run build`：通过。

### 几何探针

- 百叶三处样本点全部落在光影长廊，净高 4 > 底 3.76 + 叶 0.08
- 光槽折线每段都有墙可贴（0.6 m 半径内），朝向全部垂直于墙、朝走廊内侧
- (34, 8) 圆弧 8 段、总长 4.7 m，切点 (33,10) / (36,7)，圆心 (33,7)，
  与沉浸厅南墙（z=10）相切不穿插
- 挂画墙 52 → 50：只少 w37/slow（光槽墙）与 w35/light（条纹墙），
  容量 54 → 52；终章圆弧墙由 flatSpan 掉掉，其余不动
- 站位：出生 / 龛前 / 大厅 / 潮汐 / 临展 / 大型 / 总览 / 终章 / 终章转角内
  （34.5, 8）全通

### 冒烟截图（xvfb + 有头 chromium，`__probe` 定点）

- **慢门光槽**：正对 z=18 墙、沿墙走、转角三张——12 m 一条不断，
  绕过外角时贴着倒角走；光晕板不再压住它
- **光影百叶**：叶缝条纹从右墙拉过，洗顶光带正视时藏在叶片后
