# S2 — 场景层

## 做了什么

把 `floor.ts` 整套重写：建筑结构（S1 算好了）按分区长出来，分区色板直接用 `blueprint.ts` 里的色号。

**墙**：按 (分区, 类型) 分组建 `InstancedMesh`。主题墙（accent）占比 ~26%，优先挑**尽端墙**（与长廊走向垂直的那面——深色墙在视觉终点的设计意图），长度从长到短补足。踢脚线 `#3F413E`、高 0.075 m、厚 0.025 m，骑在墙面上。

**天花**：禁用旧的全场统一方格吊顶。长廊按「13 段 + 12 个转角」铺 3.6 m 平整顶面（重叠一块但同色同高，z-fighting 看不到），房间按各自净高（3.4 / 4.2 / 4.5 / 5 / 5.5 m）单独铺一块。**长廊的天花要先把房间的孔挖掉**——否则中央大厅 5 m 天花之上还贴着 3.6 m 的长廊顶就穿帮了。

**地面**：1.2×2.4（长廊）/ 2×2（中央/大型）/ 1.2×1.2（序厅/总览）/ 2.4×2.4（沉浸，无缝）大模块；铺缝只比底色暗 7%（规格 8% 内），配一道更淡的高光边——只在掠射角上看见分格。**拼缝方向跟着长廊走**——每段走各自的方向。

**章节分界**：每段长廊起点的铜灰嵌条（`#8C7F6E`，宽 0.1 m、横跨长廊 4 m）——规格要求的「宽 0.08–0.12 m 的铜灰色嵌条，只用于章节分界」。

**门洞**：旧版的整层高口子直接暴露，所以给每扇门加了**门楣**（门顶到天花那一截，墙材质）和**门套**（立框 + 头框，`#3E4140` 宽 0.12 m、深 0.22 m）。**浅拱券**给中央大厅与沉浸展厅用——起拱 2.35 m、矢高 1.05 m、跨 3 m 的浅拱，`THREE.Shape` + ExtrudeGeometry 现造。

**灯槽**：沿长廊中心线一条 0.2 m 宽的 emissive 光带，向主挂画墙偏 0.7 m，每 10 m 断 1.5 m——「嵌入式连续光槽，向主要挂画墙偏移 0.6–0.8 m，每隔 8–12 m 中断一次」。S3 会补上真实光源让光槽更亮。

**房间道具**：凳子（`#6B645B`，高 0.42 m）、装置占位（矮台 + 中性体块，等真作品挂上来替换）。

**材质参数**：`MeshStandardMaterial { roughness: 0.9, metalness: 0, envMapIntensity: 0.6 }`，底色用现画的矿物涂料贴图。规格里那套数字全照搬：天花 0.95、地板 0.72。

**渲染器**：曝光 0.95、ACES、SRGB、雾 `FogExp2(#D8D4CC, 0.012)`、背景 `#D8D4CC`——规格的精确值。

**纹理**：`surfaces.ts` 加了 `floorModuleTexture()`、`mineralTexture()`、`ceilingTexture()`、`thresholdTexture()`，都是 `paint()` 现画。

**删除**：旧的 `PALETTE` 常量、`makeTileGrouts`（小方格地砖）、`surface`/`wallTexture`/`REPEAT`/`SurfaceKind`（九种艺术厅形制的材质分支——新建筑直接用蓝图里的色号，不走形制表）。

**保留**：`FloorHandle` 接口完全兼容——`pickables` / `pictures` / `viewpoint` / `setHover` / `setPicture` / `setSize` / `render` / `dis` 都没变，画挂画、光晕、hover 高亮、视角的逻辑都保留。

## 自测结果

`npm run check`：**0 errors / 0 warnings / 4 hints**。`npm run build`：通过。

视觉自测（headless chromium + swiftshader）：从出生点传送到 5 个有特色的分区截图：
- **序厅**：基础暖灰白 + 长廊延伸，白底占位画框
- **中央大厅**：浅砂岩底色 + 浅拱券 + 中央大厅高 5 m（侧面看出去走廊的灯槽在拱券后）+ 门口铜灰嵌条 + 装置占位 + 长廊的天花被房间孔挖掉（没穿帮）
- **沉浸展厅**：石墨黑底色 + 同样的浅拱券（门洞开在南墙上长廊方向）
- **临展厅**：4.2 m 大空间 + 两面可移动展墙 + 柔白底色
- **大型作品厅**：5.5 m 高 + 顶面深灰 `#363837`（区别于长廊的米白）+ 主墙 + 装置占位 + 远处的走廊白光 + 灯槽

所有 5 个分区的 HUD「现在在：X」正确切换。**没有任何 console error**。

## 注意 — 顶/地面模块贴图每块单独克隆

每个地面四边形克隆了一份 `floorModuleTexture`，好按各自的尺寸设 `repeat`。建筑里有 ~30 块地面——每个克隆共享同一张 canvas 图像，只是各自有 `repeat`（值，值）和 `needsUpdate`。Texture 在 GPU 上还是同一份资源，内存几乎不增。

## 接下来做什么（S3 — 灯光）

按规格把现在的「半球光 + 环境贴图」升级成夜间叙事感：
- HemisphereLight 色温 3500 K（已经有 `#f7f4ec`）
- 环境光强度下来一些，让长廊靠 emiss灯带 + SpotLight 主导
- 灯槽换 `emissive` 材质，亮度抬上去（长廊视觉导航的核心）
- 近处 SpotLight ≤ 3 盏跟随相机，色温 3800–4200 K，光束 24°（重点）/ 30–36°（普通），不直接照摄像机
- 普通作品的 SpotLight 距离墙 0.8–1.1 m、间距 2.4–3 m，照度约为环境的 1.8–2.5 倍
- 渲染参数已经是规格值（曝光 0.95、ACES、雾 0.012、SRGB 0.012 = 规格 0.012）
- 中央大厅 3×3 m 的柔光顶棚或模拟天窗（不构造实体光源，做一个高亮平面当光顶）
- 沉浸展厅没有大面积环境照明，只留作品灯、屏幕光、地脚灯（之后 S4 才有作品）
- 远处的长廊用烘焙光或减亮的环境光，省动态阴影
