# S18 — 序厅补齐 + 潮汐之间 + P2 全馆（八边形大厅 / 斜展墙 / 锯齿墙 / 漏斗出口）

上一轮（S17）只做了序厅的三件事。这一轮把剩下的补齐：序厅欠的门垫/长凳/厚隔断、
序厅主视觉分到真作品、潮汐之间的大弧与折板顶，然后一次性推到全馆 ——
中央大厅切角成八边形 + 三级跌级、临展展墙偏 12°、大型作品厅锯齿墙、总览区漏斗出口。

## 做了什么

### 1. 序厅补齐（设计方案里写了、S17 没做的三件）

- **入口门垫**：`RoomSpec.patches` —— 地面换色的几块；序厅门口 3.2 × 1.8 m 换成
  深一档的 `#4A4741`，比房间地面高 5 mm 压在上面。（`floorMaterial/addFloor` 加了
  可选的颜色覆盖，缓存键也带上颜色）
- **长凳**：放在进门右手那块**不被长廊穿过**的角落（x 8.2, z 1.5，朝北）。
  原本按设计放在西墙前，但西墙前 x 2–6 / z 0–5 是长廊南北向那一段的走道，
  凳子会杵在正门口 —— 挪到这块安静角落，坐下来正对北墙凹龛里的主视觉。
- **短隔墙加厚到 0.3 m**：`PropSpec.partition` 加 `t`，给了厚度就画成一块长方体
  （不再是一张纸），并标 `solid`：不画中间那张平面、不往它身上挂画；
  南端伸到 z=-0.3 去接微弧后的南墙；策展文字贴到西面那一层（x 7.33）。

### 2. 序厅的主视觉分到真作品

`hang.ts` 的分区偏好表原先没有 `entry`（作品按 theme 只分给 city/night/large 与
tide/nature/light），所以序厅（还有中央大厅、临展、沉浸、总览）永远只有占位画框。
现在**每个主题的第一件给序厅**，其余按原来的顺序轮 —— 序厅拿到了 2 件真作品
（凹龛里的主视觉 + 弧墙那面），剩下的墙留白。

### 3. 潮汐之间：东墙大弧 + 三折发光顶

- 东墙整面改成弧：弦 7 m、矢高 1.2（R≈5.7），房间像个被水冲弯的洞。
- 发光顶折三折：`RoomSpec.folds`（沿一个方向分条、每条一个高度），
  4.2 / 3.95 / 4.2，折与折之间自动补一道竖向收口面 —— 不然两条顶之间会
  露出一条通到外面的缝。波纹贴图与 emissive 照旧跟着每一折走。

### 4. P2：全馆推广

| 处 | 做法 | 数据 |
|---|---|---|
| **中央大厅** | `RoomSpec.chamfer` 2.6 —— 四角各切 2.6 m，四个直角变成四道 45° 斜墙（八边形）；天花也跟着切成八边形 | 斜墙 4 道 × 3.68 m |
| **中央大厅天花** | `coffers` 一层套一层、drop 为负（往上升）：外圈 4.2 → 中环 4.6 → 中心 5.0，每级一圈 200 mm 灯槽 | 两级 |
| **临展厅** | 两片可移动展墙统一偏 12°（不再是正交网格），动线变「之」字 | ±11.86° |
| **大型作品厅** | `RoomSpec.fold` 锯齿墙：南墙四等分、偏移 [0, −0.3, +0.6, −0.3, 0] —— 同一面墙上三张画各有各的朝向 | 4 段，2.5–2.7 m |
| **总览区出口** | 漏斗：两道 0.24 m 厚的斜墙把洞口从 5 m 收到 3 m（门洞宽），上面压一块 2.8 m 的门斗天花（复用 coffer，drop 0.8） | 2 道斜墙 + 1 块门斗顶 |

新机制一共四个：`folds`（折板顶）、`chamfer`（切角）、`fold`（锯齿墙）、
`coffers`（藻井可多层嵌套、drop 可负 = 往上抬）。`coffer` 单数字段改成 `coffers` 数组。
