# S10 — 城市长廊：左墙微水泥 + 端景墙 + 洗墙灯槽

规格第三节给城市长廊的左右墙是两种性格，原来两面都是同一种矿物灰泥。这一轮补上。

## 做了什么

### 1. 左右墙各一色（新增「按前进方向分左右」的墙色）

- `Zone.sideWalls`：长廊可以分别给左墙、右墙配色
- `walls.ts` 里 `polylineWalls` 多了一个 `tintOf(mid, side)`：
  `side = +1` 时墙芯在右手边，也就是**人站在长廊里时的左墙**

城市长廊：

| 墙 | 颜色 | 材质 |
|---|---|---|
| 左 | 暖混凝土灰 `#AEA69B` | **微水泥**（新增 `microCementTexture`：更细的颗粒 + 抹刀云斑，`roughness 0.87`） |
| 右 | 暖矿物灰泥 `#D7D0C4` | 矿物涂料（`roughness 0.92`，比左墙亮一档） |

左墙 8.9 m 一整片，够放规格要的「三到五件连续城市摄影作品」；右墙作品更少 ——
不对称的展陈节奏是规格明说的。

### 2. 端景墙换成烟熏蓝灰

城市长廊的 accent（端景墙）从 `#B8AEA1` 换成规格的 **烟熏蓝灰 `#364852`**。
被选中的是 x=3 那片 10 m 的墙 —— 它垂直于西行方向，是你沿 z=10 往西走到头时
正面看到的那一面，正是「转角正对墙」。

### 3. 端景墙顶部的隐藏式洗墙灯槽

新增：分区带 `wash: true` 时，它的端景墙顶部藏一条贴顶的窄光带，
**离墙 0.95 m**（规格：洗墙灯离墙 0.9–1.1 m），光落在端景墙那件主作品上，
槽本身在视线之上。城市长廊与慢门长廊开了这一项（其它章节规格没要求）。

## 自测结果

`npm run check`：**0 errors / 0 warnings / 3 hints**。`npm run build`：通过。

几何探针（临时挂 window，用完已删）：

- 墙色分组里能取到城市那三支：左墙 `#A8A095` **roughness 0.87**（微水泥 ✓）、
  右墙 `#D7D0C4` 2 段、端景墙 `#364852` 1 段 ✓
- 洗墙灯槽 **7 条**（城市 + 慢门的端景墙各一条起的量）✓
- 新加的「城市长廊」机位（9.5, 10）五个方向平均亮度 136–183，没有大片死黑，
  抬头那张有大量高光 —— 就是光槽与洗墙带，符合预期

**一处看起来吓人、查过是正确的地方**：潮汐支廊那两个机位平均亮度掉了 16–27。
追下去是站在支廊里能斜着望进城市长廊的转角，那片 10 m 的端景墙从 `#B8AEA1`
变成了 `#364852`（渲染后 `#203040`）—— 也就是这次换色本身，不是漏光也不是错位。
