## 做了什么

`hang.ts` 重写，按规格第九节把排展规则全部补齐：

- **作品类型**：standard / hero / salon / video（浸入）
- **每一段长廊只有一面 hero 墙**：长廊里选「与走向垂直」的尽端墙（dot < 0.35），够长才当 hero（可用 ≥ HERO × 0.8 = 2.4 m）；不够就退而求其次（整面最长的墙）——这样窄一点的墙也能挂上一张主视觉
- **房间墙默认 salon**（间距 0.85 m、更密），留白规则按"整馆墙面留白"算而不是每面墙

- **每件作品只挂一次**：按主题轮着分到偏好分区（`ZONE_PREFERENCE`）——「海」先去潮汐之间再去自然长廊，「城市」先去城市长廊再去夜行、大型。加主题只需加一行
- **画心 1.52 m（规格 1.5–1.55）**、**离墙角 1.2 m**、**离门洞 0.8 m（已含在 1.2 m 预留里）**、**相邻净距 1.0 m**、**换组 2.5 m**——全部按规格
- **画框不顶到天花**：`boxOf` 在 `fh > 天花 - 0.7` 时按比例缩
- **数据暂缺挂统一中性占位画框**（不复制已有作品）：`surfaces.ts` 加了 `placeholderFrameTexture()`——中性灰底 + 双层内框，远看是「等作品的空框」
