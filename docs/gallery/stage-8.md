# S8 — 天花：按规格上色 + 章节净高

规格十一节给了每一处的天花颜色与净高，S2 只铺了「一块浅色顶」。这一轮补上。

## 做了什么

### 1. 天花颜色全部按规格换掉

| 分区 | 原来 | 现在（规格） |
|---|---|---|
| 夜行长廊 | `#F1EEE7` | `#D8D0C5` |
| 城市长廊 | `#F1EEE7` | `#DDD8CF` |
| 自然长廊 | `#F1EEE7` | `#D5D9D2` |
| **光影长廊** | `#F1EEE7` | **`#403A37`（暗顶）** |
| **慢门长廊** | `#F1EEE7` | **`#283338`（暗顶）** |
| 终章长廊 | `#F1EEE7` | `#CFC9BE`（规格没给，按「收束」压一档） |
| 中央大厅 | `#EFEAE0` | `#E3DDD2` |
| 潮汐之间 | `#F1EEE7` | `#DCE0D9` |
| 临展厅 | `#F1EEE7` | `#E2DED6` |
| 沉浸展厅 | `#181B1D` | `#0F1213` |
| 大型作品厅 | `#363837` | `#2C2E2D` |
| 总览区 | `#F1EEE7` | `#E6E0D6` |

暗顶那两处（光影、慢门）顺带把墙顶 30 mm 的暗石墨缝也开了 —— 规格说的是
「墙面与**深色**天花之间可留 30 mm 缝」，浅顶的区域不开。

### 2. 章节净高：自然 3.8、光影 4.0

原来长廊墙高写死 `CORRIDOR.height`（3.6），天花也是 3.6。现在：

- **墙高按分区**：`polylineWalls` 的高度改成由中点所在章节决定；
- **天花按分区**：`ceilingY(band)` 取代原来的固定 3.6（支廊不是章节，仍按长廊标准高）；
- 灯槽跟着所在弧段的天花走，不再一律挂在 3.6。

### 3. 转角那块天花压到较低的一档 + 两道竖向收口

这是本轮唯一要动脑子的地方。转角那块 4×4 的顶横跨转角前后各 2 m，
而墙是一段一个高度 —— 如果转角顶按「进来那一章」给（比如光影 4.0），
它伸进慢门那一段（墙 3.6）之后，**墙顶与天花之间就会露出一条 0.4 m 通到外面的缝**。

处理：转角那块压到前后两章里**较低的那一档**，然后在转角前后各 2 m 补一道竖向收口
（一片墙材质、垂直于长廊方向）。效果是每转一个弯，天花换一次高度，换的地方有收口 ——
正好对应规格「天花高度有变化」。

## 自测结果

`npm run check`：**0 errors / 0 warnings / 3 hints**。`npm run build`：通过。

两项几何探针（临时把场景挂到 window 上，用完已删）：

- **天花连续性**：沿折线每 0.5 m 取样 224 点，找天花的点 **224/224** —— 没有漏到外面的窟窿；
  各章实测高度：夜行 3.6 / 城市 3.6 / 自然 3.8 / 光影 4.0 / 慢门 3.6 / 终章 3.6
  （3.4 与 5.0 是序厅、中央大厅的房间顶盖过长廊，原来就这样）。
- **墙顶漏光**：71 片真墙、213 个取样点，墙顶低于天花的 **8 处**，逐条看过都不是漏：
  - 3 处是序厅那道 3 m 短隔墙、3 处是沉浸展厅 3.6 m 偏心隔墙 —— 都是**故意**让人看过去的；
  - 2 处是中央大厅与潮汐之间矩形重叠出来的 1×2 m 死角，四面都是墙、人进不去。
  （改之前是 11 处，其中 3 处是真的漏 —— 就是上面说的转角那道。）
- 共面异材质对 **41**，与上一轮持平（新增的收口是竖面，不参与水平共面）。
- 20 个机位画面对比：只有往上看的那几个机位变暗（大型作品厅 −8、潮汐支廊 −7），
  与人视机位基本不变 —— 就是换顶色该有的量，没有整片变黑。
