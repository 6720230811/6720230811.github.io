# S11 — 三处光的细节

规格里剩下的三处「光」，都是小件。

## 做了什么

### 1. 潮汐之间：天花烘一层极轻微的波纹明暗

规格：「大面积漫射柔光，**可增加极轻微的波纹状明暗变化**，但**不能出现动态水纹投影**」。

做法是 `ceilingTexture(base, ripple)` 多一个开关：把几道极淡的明暗波浪**烘进贴图**
（`rgba(255,255,255,0.045)` / `rgba(0,0,0,0.030)`，振幅约 ±2.4%）。
它是贴图的一部分，所以**永远不动** —— 既没有动画也没有投影，规格那条禁令自动满足。
只有潮汐之间开了（`Zone.ceilingRipple`）。

### 2. 临展厅：规则但简洁的轨道灯

规格：「使用规则但简洁的轨道灯系统，轨道和灯具颜色 `#363938`」。

- 3 条平行轨横贯房间（沿长边），按进深均分、两端各留一截，贴在天面下 5 cm；
- 每 2.6 m 一个灯具（深色小方块，悬在轨下 12 cm）；
- 轨道与灯具都是 `#363938`，**灯具不发光** —— 照亮作品是作品灯（SpotLight 池）的活儿，
  轨道灯只负责「这间厅的照明是规则的」这件事。
- 全部走门洞那套 `BoxJob` 合批，只多一个 InstancedMesh。

### 3. 沉浸展厅：低亮度安全引导光

规格：「所有结构和灯具尽量隐藏，**仅在入口和地面边缘设置低亮度安全引导光**」。

- 地面边缘那四点地脚灯从 `emissiveIntensity 2.2` 压到 **0.85**，颜色也从亮琥珀
  `#F0C48A` 换成更沉的 `#B98A57`；
- 门内新增一条贴地引导线：门洞往房间里 0.5 m、宽度跟门洞走（3.2 m），
  用的是同一支低亮度材质 —— 进门那一下有东西领着，但不刺眼。

## 自测结果

`npm run check`：**0 errors / 0 warnings / 3 hints**。`npm run build`：通过。

几何探针（临时挂 window，用完已删）：

- 天花贴图逐行明暗波动：全馆 31 张里**只有 2 张是 6.1**（就是潮汐顶那两片，
  采样色 `#DDE1DA` ≈ `#DCE0D9` 被波纹推了一点点），其余都是 0.1 ——
  波纹只加在该加的地方，幅度 ±2.4%，确实「极轻微」
- 临展厅轨道灯：**3 条轨 + 15 个灯具**，材质颜色 `#363938` ✓
- 沉浸厅引导光：4 个地面灯（intensity 0.85）+ 门内那条 3.2 m 引导线（y=0.02，
  位置在门内 0.5 m）✓
